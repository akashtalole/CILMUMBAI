# Ward audit rubric (starter; tune the criteria)

- `/mnt/session/outputs/ward-brief.md` exists, is at most one page (about 450 words), and names the ward.
- Every amount, date, contractor and tender number in the brief and in each case file is followed by a source id and page.
- Each file in `/mnt/session/outputs/cases/` has an evidence table, a "what is not known" section, and a matching `.challenge.md` review whose verdict is `publish` or `publish with changes`.
- Every change a challenge review asked for has been made in the case file it reviews.
- No case file or brief uses the words fraud, scam, corrupt, cartel, nexus or siphoned, and no official is named except by post.
- Each case file the Challenger held is in `/mnt/session/outputs/held/` with the reason, and not in `cases/`.
- `/mnt/session/outputs/gaps.jsonl` has one line per missing record, naming the record and the office that holds it.
- Each gap has a matching RTI draft in `/mnt/session/outputs/drafts/`, addressed to a Public Information Officer and asking for documents by name and period.
- Where the graph returned nothing for a check, the brief says so instead of leaving the section out.
